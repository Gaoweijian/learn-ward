繁 花

金宇澄 著

说书人导读版
上海话版中国版《清明上河图》。60年代的纯真与压抑，90年代的繁华与虚无， 两条时间线交替讲述，"不响"是全书最深的沉默。

📌 这本书是什么

2013年出版，2015年获茅盾文学奖。
以上海话语感写就，描写上海60-70年代和90年代两个时期， 三条主线：阿宝（商人）、沪生（律师）、小毛（工人）， 以及围绕他们的众多男女。

📌 怎么读这本书

全书没有统一主线，像上海弄堂的散漫闲谈，每章都有多条故事并行。 "不响"是全书最重要的叙事手法：沉默比言语更有力量。 两个时代交替出现，读者需自己拼接时间线。

🏆 为何获茅盾文学奖

金宇澄首次在严肃文学中大规模使用沪语叙事， 复原了一个消失中的上海。评委认为：小说用碎片化结构 呈现了现代都市人的孤独与沉默，形式即内容。

⭐ 读书小白入门建议

建议从引子开始，感受叙事氛围。 再看人物关系图认清主要人物。 每章导读都有沪语对白翻译和普通话讲述，不懂上海话也能读懂。
