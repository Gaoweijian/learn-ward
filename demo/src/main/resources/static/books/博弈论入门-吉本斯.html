第一章

完全信息静态博弈

最基础的博弈形式：每个人都同时做决定，而且彼此知道对方的所有信息。听起来简单，但里面藏着的智慧超乎想象。

1.1 博弈的基本要素

核心概念

一个博弈由三个核心要素组成：参与者（谁在玩？）、策略（可以选什么？）、收益（选了之后得到什么？）。完全信息意味着每个人对所有要素都一清二楚。

生活化例子
石头剪刀布

参与者：你和我（两个玩家）

策略：出石头、出剪刀、出布（每人3个策略）

收益：赢=+1，输=-1，平=0

这就是一个"2人、每人3策略、完全信息、同时出拳"的博弈。你不知道对方出什么，但你清楚对方有哪3个选项，这就叫"完全信息"。

数学简化版
石头剪刀布收益矩阵
对方出石头对方出剪刀对方出布
你出石头0, 0+1, -1-1, +1
你出剪刀-1, +10, 0+1, -1
你出布+1, -1-1, +10, 0

括号里的两个数字分别是"你的收益"和"对方的收益"。比如你出石头、对方出剪刀 → 你+1，对方-1。

小白理解要点
  • "完全信息"≠"我知道你要出什么"。它只是说我知道你有哪些选项，不知道你具体选哪个。
  • "静态"=同时决策。不是说你们必须同时举手，而是你做决定的时候不知道对方已经选了什么。
  • 收益是博弈的"计分板"，决定了每个人的动机。
常见迷思
✗
"完全信息就是我知道对方在想什么"
完全信息只意味着你知道对方"能选什么"和"选了能得什么"，不代表你读懂了对方的心思。知道选项≠知道选择。

1.2 严格优势策略

核心概念

严格优势策略（Strictly Dominant Strategy）就是：无论对方怎么选，你选这个策略都比选其他任何策略更赚。这是一个"闭着眼睛都不会选错"的选择。

生活化例子
考驾照科三的焦虑

假设你要选驾校，有"认真学"和"混过去"两种策略。无论驾校教得好不好（对方的选择），认真学的通过率都比混过去高。

那么"认真学"就是你的严格优势策略——无论驾校怎么样，这都是你更好的选择。

数学简化版
优势策略示例（你的收益）
驾校教得好驾校教得一般
认真学90分80分
混过去70分50分

"认真学"在每一列都大于"混过去" → 认真学是严格优势策略。

策略A严格优于策略B ⟺ 对所有s₂，u₁(A, s₂) > u₁(B, s₂)
小白理解要点
  • 如果存在严格优势策略，理性的决策者一定会选它——不需要猜测对方。
  • 但现实中严格优势策略很罕见，因为大多数情况下"最好的选择"取决于对方怎么选。
  • 当一个博弈中所有参与者都有严格优势策略时，这个博弈的结局就是确定的。
常见迷思
✗
"优势策略就是能赢的策略"
优势策略不一定保证赢，它只保证比你的其他选项好。比如考试中认真学也未必满分，但比不学强。

1.3 纳什均衡

核心概念

纳什均衡（Nash Equilibrium）是博弈论最核心的概念。简单说：在一个策略组合中，每个参与者都"不想单方面改变"自己的策略——因为改了反而更差。大家都觉得"在对方这个选择下，我现在的选择就是最好的"。

生活化例子
经典案例：囚徒困境

两个嫌疑人被抓，分别审讯。每人可以选择"沉默（合作）"或"坦白（背叛）"：

• 两人都沉默 → 各判1年（最轻）

• 一人坦白一人沉默 → 坦白的直接释放，沉默的判10年

• 两人都坦白 → 各判5年

虽然两人都沉默（各1年）是最优结果，但每个人都有动机坦白——因为不管对方怎么选，坦白都是更"安全"的。结果两人都坦白（各5年），这就是纳什均衡。

数学简化版
囚徒困境收益矩阵（刑期，越低越好）
对方沉默对方坦白
你沉默-1, -1-10, 0
你坦白0, -10-5, -5 ★

★ 标记的格子就是纳什均衡：双方都坦白。谁单方面改沉默，自己的刑期就从-5变成-10，更差了。

纳什均衡 (s₁*, s₂*, ... , sₙ*)：对所有 i 和所有 sᵢ ∈ Sᵢ，uᵢ(sᵢ*, s₋ᵢ*) ≥ uᵢ(sᵢ, s₋ᵢ*)
小白理解要点
  • 纳什均衡不一定是最优的！囚徒困境中，(沉默,沉默)比(坦白,坦白)对双方都好，但它不是均衡。
  • 纳什均衡只是"稳定的状态"——没人有动力单方面离开，不意味着这个状态对所有人最好。
  • 一个博弈可以有多个纳什均衡，也可以只有一个，甚至可能没有纯策略纳什均衡。
  • 约翰·纳什因此获得1994年诺贝尔经济学奖。
常见迷思
✗
"纳什均衡就是最优解"
纳什均衡是"稳定解"而非"最优解"。它意味着没人想单方面改变，但所有人的境况可能比另一种安排更差。囚徒困境就是最好的反例。
✗
"纳什均衡一定是唯一的"
一个博弈可能有零个、一个或多个纳什均衡。存在多个均衡时，需要其他方法（如聚焦点、协调）来预测实际结果。

1.4 混合策略均衡

核心概念

有时候，纯策略（固定选一个）没有纳什均衡，但混合策略（以一定概率随机选择）可以有。混合策略纳什均衡就是：每个人都按某个概率分布随机选择，使得对方换任何纯策略的期望收益都一样。

生活化例子
猜拳游戏为什么要随机出

石头剪刀布这个游戏，不存在纯策略纳什均衡——无论你固定出什么，我都能找到克制你的策略。

但如果我以1/3概率出石头、1/3出剪刀、1/3出布（完全随机），你就找不到更好的策略来应对。这就是混合策略纳什均衡——让对方"猜不透"就是你的最优策略。

数学简化版
混合策略 σᵢ 是纯策略集 Sᵢ 上的概率分布
σᵢ = (p₁, p₂, ..., pₖ)，其中 pⱼ ≥ 0 且 p₁+p₂+...+pₖ = 1

纳什定理（1950）：每个有限博弈都至少存在一个混合策略纳什均衡。

这意味着纳什均衡普遍存在——你永远可以找到一个"没人想单方面偏离"的概率组合。

小白理解要点
  • 混合策略不是"犹豫不决"，而是"故意随机化"来让对手无法利用你的规律。
  • 在体育比赛中，罚球手踢左还是右、守门员扑左还是右，经典模型就是混合策略博弈。
  • 纳什的存在性定理保证了至少一个均衡存在——这就像数学中的"不动点定理"。
常见迷思
✗
"混合策略就是随便乱选"
混合策略是精心计算的概率分布。比如足球罚球中，如果罚球手偏左的射门成功率高，他应该调整左右概率让守门员的期望收益相等。这是有最优解的，不是"随便选"。

1.5 应用：古诺竞争

核心概念

古诺竞争（Cournot Competition）是寡头市场中企业同时选择产量的模型。每家企业在决定生产多少时，会把对方的产量当作"给定的"（即认为对方不会因自己的选择而改变）。均衡时，没有企业有动机单方面改变产量。

生活化例子
奶茶店选址竞争

假设一条街上只有两家奶茶店（你和我），每天的顾客总数是固定的。如果两家都生产很多（都大量备货），供过于求，价格下降，两家都亏。

如果你知道对方今天备了100杯的料，你会想：我备多少最赚？太少赚不够，太多卖不完浪费。这就是古诺竞争的核心——在预测对方产量的前提下，选择自己的最优产量。

数学简化版
线性需求：P = a - Q = a - (q₁ + q₂)
企业1的利润：π₁ = q₁ × (a - q₁ - q₂) - c×q₁
古诺均衡产量：q₁* = q₂* = (a - c) / 3

关键洞察：两家企业的总产量 (2(a-c)/3) 大于垄断产量 ((a-c)/2)，但小于完全竞争产量 (a-c)。这就是"竞争让消费者受益，但少于完全竞争"的含义。

小白理解要点
  • 古诺模型中，企业竞争的手段是"产量"，不是"价格"。
  • 反应函数（Best Response Function）描述了给定对方产量时自己的最优产量。
  • 古诺均衡就是两条反应函数的交点——双方都不想改了。
  • 企业越多，均衡越接近完全竞争，价格越低。
常见迷思
✗
"古诺竞争中企业会合作限产来抬价"
在基本的古诺模型中，企业是独立决策的，不合作。如果合作限产，双方利润确实更高（回到垄断水平），但这不是纳什均衡——每方都有动机偷偷多生产。这就是囚徒困境的经济学翻版。

1.6 应用：伯特兰竞争

核心概念

伯特兰竞争（Bertrand Competition）与古诺相反：企业同时选择价格而非产量。在产品同质的情况下，消费者只会买最便宜的，因此均衡结果出人意料——只要有两家企业竞争，价格就会降到边际成本。

生活化例子
小区门口的水果摊

两家水果摊卖一模一样的苹果，进货价都是3元/斤。如果A卖5元，B卖4元，所有人都会去B那里买。

B想：我卖4元已经抢到所有客户了，那我卖3.5元呢？利润少了但客户不变。A想：那我卖3.1元，薄利多销。

最终两家都会把价格压到3元——刚好等于进货成本，谁也赚不到额外利润。这就是"伯特兰悖论"：只需两家企业就能达到完全竞争的价格。

小白理解要点
  • 伯特兰悖论说明：价格竞争比产量竞争激烈得多。两家的价格战就能把利润打光。
  • 现实中为什么没有这么极端？因为产品有差异（品牌、服务、位置）、产能有限制、企业存在其他约束。
  • 古诺竞争和伯特兰竞争是两种极端的竞争模式，现实介于两者之间。
第二章

完全信息动态博弈

当决策有了先后顺序，"先下手"和"后发制人"就变得截然不同。博弈树替代了收益矩阵，成为新的分析工具。

2.1 扩展式博弈

核心概念

扩展式博弈（Extensive-Form Game）用博弈树来描述有先后顺序的博弈。树的节点代表"轮到谁做决定"，分支代表"可以选什么"，末端代表"最终收益"。相比静态博弈的矩阵，博弈树能清楚地展现决策的时序和信息结构。

生活化例子
市场进入博弈

一个新品牌想进入市场：

第一步：新品牌选择"进入"或"不进入"

第二步（如果新品牌进入）：在位者选择"打价格战"或"和平共处"

结果：进入+共处 → 双方都赚钱；进入+价格战 → 双方亏损；不进入 → 在位者独享利润。

这种"先后有序"的场景，用博弈树画出来一目了然。

数学简化版
扩展式博弈 = (N, H, P, ƒₐ, uᵢ)

N = 参与者集合，H = 历史集合（所有可能的行动序列），P = 参与者函数（谁在哪个节点做决策），ƒₐ = 可行行动函数，uᵢ = 收益函数。

信息集（Information Set）是扩展式中的关键概念：如果后行动者不能区分某些节点，这些节点就属于同一个信息集——代表"虽然轮到你了，但你不知道具体处于哪个节点"。

小白理解要点
  • 静态博弈用矩阵，动态博弈用博弈树——这是最直观的区别。
  • 信息集用虚线连接的节点表示：你在这个决策点，但不知道具体是哪一条路径到达的。
  • 如果所有信息集都是单点（即每个节点都能区分），这就是"完美信息"博弈，如国际象棋。

2.2 逆向归纳法

核心概念

逆向归纳法（Backward Induction）是求解完美信息动态博弈的核心方法：从博弈树的最末端开始，倒推每个参与者在每个节点会怎么做，最终得出第一个行动者的最优选择。

生活化例子
最后通牒博弈

我拿到100元，可以分给你一部分。我提出方案后你选择"接受"或"拒绝"。拒绝则两人都拿0元。

逆向推理：最后一步，你面对我给你的金额X，接受得X，拒绝得0 → 理性的你会接受任何 X > 0。知道了这一点，我在第一步就会给你最少的钱（比如1元），自己留99元。

这就是逆向归纳法的威力——从最后一步开始推理，一步步倒推出整个博弈的结局。

小白理解要点
  • 逆向归纳法的前提是"完美信息"——每一步都知道之前发生了什么。
  • 最后通牒博弈的理论预测（给1元）与现实不符——人们会出于"公平感"拒绝过低的分配。这说明纯粹的理性人假设有局限。
  • 逆向归纳法得到的均衡一定是子博弈完美均衡（下节讲）。

2.3 子博弈完美均衡

核心概念

子博弈完美纳什均衡（Subgame Perfect Nash Equilibrium, SPNE）是泽尔腾（Selten, 1994年诺贝尔奖得主）提出的概念。它要求：不仅在整体博弈中是纳什均衡，而且在每一个子博弈中也是纳什均衡。这排除了"空洞威胁"——那些说着玩的、不会被真正执行的策略。

生活化例子
空头威胁 vs 可信威胁

市场进入博弈中，在位者威胁"如果你进入，我就打价格战"。

• 空头威胁：如果新品牌真的进入了，打价格战对在位者亏得更多。所以在位者实际上不会打。这个威胁不可信。

• 可信威胁：如果在位者在进入之前已经投入大量沉没成本（比如建了巨大产能），那么打价格战的成本就低了，威胁就变得可信。

子博弈完美均衡剔除了空头威胁——只保留每个节点上都是最优选择的策略。

小白理解要点
  • 子博弈完美均衡 = 逆向归纳法的结果。在有限完美信息博弈中，两者等价。
  • SPNE是纳什均衡的"精炼"——纳什均衡允许空洞威胁，SPNE不允许。
  • 这就是为什么谈判中"说到做到"比"随便说说"更有力量——SPNE只承认可信的承诺。

2.4 重复博弈与合作

核心概念

当同一个博弈重复进行多次，结果会与单次博弈截然不同。在无限重复博弈中，即使是囚徒困境这样的"不合作"博弈，也可以通过"以牙还牙"等策略实现合作均衡。无名氏定理（Folk Theorem）给出了更一般的结果：只要参与人有足够的耐心，几乎任何合理的收益都可以被维持为均衡。

生活化例子
为什么小区便利店不卖假货

单次博弈中，卖假货能赚更多（类似囚徒困境中的"坦白"）。但便利店要经营很久（重复博弈），如果卖一次假货被发现，以后就没人来了。

• 以牙还牙策略（Tit-for-Tat）：第一轮合作，之后每轮模仿对方上一轮的做法。你合作我也合作，你背叛我也背叛。

这个策略简单但极其有效——在 Axelrod 的计算机锦标赛中，"以牙还牙"击败了所有复杂的策略。

小白理解要点
  • 单次博弈 → 不合作（囚徒困境）；重复博弈 → 可能合作。这就是"长期关系改变行为"的博弈论解释。
  • 贴现因子 δ 衡量"耐心程度"：越接近1说明越有耐心，越看重未来收益。
  • 有限次重复博弈的最后几轮又会退化成不合作——"最后一天了，捞一把就跑"。
常见迷思
✗
"重复博弈一定能实现合作"
合作需要条件：参与者有足够耐心（贴现因子够大）、能观察到对方行为、有惩罚背叛的能力。如果只重复2-3次，或者大家都急功近利，合作仍然难以实现。

2.5 应用：斯塔克尔伯格模型

核心概念

斯塔克尔伯格模型（Stackelberg Model）是古诺模型的动态版本：一家企业（领导者）先选择产量，另一家（跟随者）在观察到领导者的产量后再选择自己的产量。这种"先动优势"模型常见于市场中已有强势企业和新进入者的场景。

生活化例子
大品牌先发布新品

苹果先发布新手机（领导者），确定了市场定位和功能配置。安卓厂商观察到苹果的配置后，再决定自己的产品策略（跟随者）。

领导者因为"先动"，可以利用跟随者的反应来优化自己的选择——它知道跟随者会怎么回应，因此可以做出更有利的决策。

小白理解要点
  • 领导者有"先动优势"：产量通常高于古诺均衡，利润也更高。
  • 跟随者虽然后动，但可以利用"信息优势"——它看到了领导者的选择。
  • 先动 vs 后动，哪个更好取决于具体场景，没有绝对优劣。
第三章

不完全信息静态博弈

现实中最常见的情况：你不知道对方的底牌。不知道对方的真实成本、真实偏好、真实能力……怎么办？贝叶斯博弈给了我们一套在"不确定性"中做决策的框架。

3.1 贝叶斯博弈的基本框架

核心概念

贝叶斯博弈（Bayesian Game）引入了类型（Type）的概念。每个参与者有一个只有自己知道的"类型"（比如自己的真实成本、真实能力），其他参与者只知道类型的概率分布。决策就是在"不知道对方真实类型"的情况下做出的。

生活化例子
二手车的柠檬问题

卖家知道自己的车是好车（"桃子"）还是坏车（"柠檬"），买家不知道。买家只知道"市场上70%是好车，30%是坏车"这个概率。

• 卖家的类型：{好车卖家, 坏车卖家}，这是卖家自己知道的

• 买家只知道概率分布：P(好车)=0.7, P(坏车)=0.3

买家要在这个不确定性下决定出多少钱——出高了怕被坑，出低了可能错过好车。这就是贝叶斯博弈。

数学简化版
贝叶斯博弈 = (N, {Aᵢ}, {Tᵢ}, {pᵢ}, {uᵢ})

Tᵢ = 参与者 i 的类型集合，pᵢ = 关于他人类型的信念（概率），uᵢ = 依赖于自己类型和所有人行动的收益函数。

策略变成了类型依赖的策略：sᵢ(tᵢ) 表示"如果我是类型 tᵢ，我就选策略 sᵢ"。

小白理解要点
  • "不完全信息"≠"完全不知道"。你不知道对方的真实类型，但你知道类型的概率分布。
  • "类型"可以代表任何私人信息：成本高低、能力强弱、风险偏好、产品好坏等。
  • 贝叶斯博弈是海萨尼（Harsanyi, 1994年诺贝尔奖得主）的贡献，他巧妙地将"不知道"转化为"面对自然的随机选择"。

3.2 贝叶斯纳什均衡

核心概念

贝叶斯纳什均衡（Bayesian Nash Equilibrium）是不完全信息静态博弈的解概念。在均衡中，每个参与者在给定自己类型的条件下，选择的最优策略也是针对其他人类型依赖策略的最佳回应。

生活化例子
古董拍卖

你在古董拍卖会上竞拍一件瓷器。你不知道其他人对这件瓷器的估价（他们的"类型"），只知道估价的大致范围。

在贝叶斯纳什均衡中：每个人的出价策略取决于自己的估价，且在给定"其他人的出价策略"后，你的出价策略对你来说是最优的。

直觉上：你不知道别人值不值这个价，但你根据自己的估价和概率判断来决定出多少。

小白理解要点
  • 贝叶斯纳什均衡 = 纳什均衡 + 类型依赖策略 + 信念（概率）。
  • 每个类型都"最优回应"其他人的类型依赖策略 → 这就是均衡的含义。
  • 完全信息纳什均衡是贝叶斯纳什均衡的特例（只有一个类型时）。

3.3 拍卖理论入门

核心概念

拍卖是贝叶斯博弈最经典的应用场景。2020年诺贝尔经济学奖得主米尔格罗姆和威尔逊（Milgrom & Wilson）的工作就主要在拍卖理论。核心问题是：在不知道对方估价的情况下，如何设计拍卖规则来实现最优结果？

生活化例子
四种常见拍卖形式

英式拍卖（递增出价）：从低价开始，大家轮流加价，价高者得。像淘宝拍卖、艺术品拍卖。买家会根据别人的出价逐步调整自己的估值。

荷式拍卖（递减出价）：从高价开始往下喊，第一个喊"停"的人得到商品。像菜市场批量甩卖。

第一价格密封拍卖：每人偷偷写一个价格交给拍卖师，价高者得，付自己写的价。像招标。

第二价格密封拍卖（维克里拍卖）：价高者得，但只付第二高的价格。你会在淘宝上看到类似的"出价代理"机制。

小白理解要点
  • 维克里拍卖（第二价格）的一个神奇性质：真实出价是最优策略——你写自己的真实估价，永远不会亏。
  • 拍卖设计需要考虑"赢者诅咒"：在共同价值拍卖中（如石油开采权），赢家往往是过度乐观的那个，实际可能亏钱。
  • 收入等价定理：在一定条件下，四种拍卖形式给拍卖者带来的期望收入是相同的。

3.4 机制设计初探

核心概念

机制设计（Mechanism Design）是博弈论的"逆向工程"：不是分析给定的博弈规则下会发生什么，而是设计博弈规则来达到你想要的结果。2007年诺贝尔经济学奖（赫维茨、马斯金、迈尔森）就颁给了这个领域。

生活化例子
如何让大家说实话

假设你要组织一次聚餐，需要大家报自己能出多少钱。

如果直接问，大家都会低报（为了少出钱）。但如果设计一个规则：报的价格最低的人请所有人吃饭——那么大家都会真实报出自己的承受能力（因为报低了反而亏更多）。

这就是机制设计的核心：设计规则让人自愿说真话，不需要知道对方的真实想法。

小白理解要点
  • 机制设计的两大核心条件：激励相容（Incentive Compatibility，说真话是最优选择）和个人理性（参与约束，每个人都愿意参加）。
  • 显示原理（Revelation Principle）：任何机制能实现的结果，都可以通过一个"激励相容的直接机制"来实现。
  • 应用广泛：拍卖设计、匹配市场（如医生-医院匹配、学校录取）、投票制度、合同设计等。
第四章

不完全信息动态博弈

这是博弈论中最复杂的类型——既不知道对方的底牌，决策又有先后顺序。你不仅要在不确定性中做选择，还要通过观察对方的行动来推断对方的类型。信号传递和信号甄别成为核心。

4.1 完美贝叶斯均衡

核心概念

完美贝叶斯均衡（Perfect Bayesian Equilibrium, PBE）将贝叶斯推断与子博弈完美性结合起来。要求：（1）在每个信息集上，参与者的信念（关于"我在哪个节点"的概率判断）是理性的——用贝叶斯法则更新；（2）给定这些信念，每个参与者的策略都是最优的。

生活化例子
通过行为判断人品

你认识一个新朋友，不知道TA是"大方的人"还是"小气的人"（这是TA的类型，你不知道）。

第一次约会，TA主动买单（行动）。你观察到这个行为后，更新你的判断："大方的人"概率上升了。

第二次约会，你根据更新后的判断决定自己的行为。这就是完美贝叶斯均衡的核心——边做边学，边学边调。

小白理解要点
  • 完美贝叶斯均衡 = 纳什均衡 + 贝叶斯信念更新 + 序贯理性。
  • "信念"就是概率判断——你在某个信息集上对"处于哪个节点"的概率估计。
  • PBE在不完全信息动态博弈中扮演的角色，类似于SPNE在完全信息动态博弈中的角色。

4.2 信号传递博弈

核心概念

信号传递博弈（Signaling Game）是不完全信息动态博弈的典型形式：拥有私人信息的一方（发送者）先采取行动，这个行动可以传递关于自己类型的"信号"；另一方（接收者）观察信号后更新信念，然后做出反应。问题是：信号是可信的吗？

生活化例子
孔雀开屏 = 发信号

生物学中最经典的信号博弈：雄孔雀拖着又大又重的尾巴（成本很高的信号）来吸引雌孔雀。尾巴越大，说明这只能活下来（身体健康），因为虚弱的孔雀根本拖不动这么大的尾巴。

• 发送者：雄孔雀，类型是{强壮, 虚弱}，信号是尾巴大小

• 接收者：雌孔雀，观察尾巴大小后选择{接受, 拒绝}

• 关键：只有强壮的孔雀能承担"大尾巴"的成本 → 信号是分离均衡，雌孔雀可以通过尾巴大小准确判断雄孔雀的类型。

小白理解要点
  • 信号要有效，必须满足"单交叉条件"（Spence-Mirrlees condition）：不同类型发出信号的"成本"必须不同。成本低的人才能发出强信号。
  • 分离均衡：不同类型发出不同信号 → 接收者能准确识别类型（如学历信号）。
  • 混同均衡：所有类型发出相同信号 → 接收者无法区分（如面试中所有人都说"我有团队精神"）。
  • 半分离均衡：部分类型信号相同，部分不同 → 接收者只能部分推断。
常见迷思
✗
"信号越强，说明实力越强"
不一定。只有当强信号对"弱者"来说成本太高时，信号才是可信的。如果发信号没有成本差异（比如谁都能花钱做广告），信号就没有信息含量。

4.3 信号甄别博弈

核心概念

信号甄别（Screening）与信号传递的顺序相反：不知情的一方（接收者）先行动，设计一个"方案"（如合同），让对方（拥有私人信息的一方）来选择。不同类型的人会选择不同的方案，从而自动暴露自己的类型。

生活化例子
保险公司的分层定价

保险公司不知道你开车是"安全型"还是"冒险型"。但保险公司可以设计两个方案：

• 方案A：低月费 + 高免赔额（适合安全驾驶者，因为几乎不需要理赔）

• 方案B：高月费 + 低免赔额（适合冒险驾驶者，因为经常需要理赔）

安全驾驶者会自动选A，冒险驾驶者会自动选B → 保险公司不需要知道你的类型，通过方案设计就能自动区分。

小白理解要点
  • 信号传递：知情方先动（孔雀开屏），信号甄别：不知情方先动（保险公司设计方案）。
  • 核心思想都是通过"成本差异"来分离不同类型的人。
  • 现实中两者常常同时存在：企业既发信号（广告、品牌），也设计甄别方案（定价策略、合同条款）。

4.4 应用：劳动力市场信号

核心概念

这是斯彭斯（Spence, 2001年诺贝尔奖得主）的经典模型：学历作为劳动能力的"信号"。企业不知道求职者的真实能力，但观察到求职者的学历。高能力者获得高学历的"成本"（如学习负担）比低能力者低，因此高学历成为高能力的可信信号。

生活化例子
为什么考名校那么拼命

假设有两类人：高能力（生产率=10）和低能力（生产率=5）。企业愿意付的工资=期望生产率。

如果没有学历信号，企业只能付市场平均工资7.5，高能力者亏了。

如果名校录取标准足够严格，使得低能力者考上名校的概率极低（成本极高），那么名校学历就成为高能力的可信信号。企业看到名校毕业就给高薪，高能力者通过学历"证明"了自己。

注意：这里的学历可能并不直接提升能力，它只是"证明能力"的信号。这是信号传递博弈的核心洞察。

小白理解要点
  • 学历信号模型解释了为什么人们愿意为"名校光环"付出巨大代价——因为信号有经济价值。
  • 但也揭示了一个社会效率问题：如果教育只发挥"信号"功能而不提升实际能力，那大量教育投入可能是社会资源的浪费。
  • 这也解释了"学历贬值"现象：当越来越多的人获得高学历，信号的区分力下降，需要更高的学历来传递同样的信号。

4.5 应用：公司投资信号

核心概念

公司管理层比外部投资者更了解公司的真实价值（信息不对称）。管理层可以通过某些决策向市场传递"公司前景很好"的信号——比如发行债务而非股票、提高分红、进行大规模投资等。

生活化例子
为什么好公司发债而不发股

假设一家公司需要融资。投资者不知道公司是"优质公司"还是"劣质公司"。

如果公司选择发行债券（需要还本付息）：劣质公司不敢借太多，因为还不起会破产。优质公司才敢借——因为它的未来现金流足够偿还。

所以"敢于借债"本身就是一个信号：告诉市场"我有信心还钱"。投资者观察到发债行为后，会提高对公司质量的评估。

小白理解要点
  • "信号成本"是关键：只有好公司能承担的成本，才能传递可信的信号。
  • 股利信号理论：提高分红 = 管理层对公司前景有信心（因为减少了内部可用资金）。
  • 这个模型解释了很多公司金融现象：为什么IPO后股价常常波动、为什么融资方式的选择本身会传递信息。
常见迷思
✗
"公司做的一切都是为了传递好信号"
信号传递是副产品，不是目的。公司首先做出最有利于自己的经营决策，市场从这些决策中"读取"信号。刻意做"信号"而不顾经营实质，就是"假大空"了。

博弈论四大分支速查表
静态（同时决策） 动态（先后决策）
完全信息 纳什均衡
经典案例：囚徒困境、古诺竞争		 子博弈完美均衡
经典案例：逆向归纳、重复博弈
不完全信息 贝叶斯纳什均衡
经典案例：拍卖、机制设计		 完美贝叶斯均衡
经典案例：信号传递、信号甄别
一句话总结
  • 完全信息 + 静态 → 大家同时做决定，彼此了解规则。核心工具：纳什均衡。
  • 完全信息 + 动态 → 有先后顺序，后来者能观察。核心工具：逆向归纳 / 子博弈完美均衡。
  • 不完全信息 + 静态 → 同时做决定，但不知道对方底牌。核心工具：贝叶斯纳什均衡。
  • 不完全信息 + 动态 → 先后做决定，且不知道对方底牌，但可以从行为推断。核心工具：完美贝叶斯均衡。
核心启示

博弈论教会我们三件事：

第一，你的最优选择取决于对方的选择。不存在"放之四海而皆准"的最优策略，一切都在互动中决定。

第二，承诺和威胁只有在"可信"时才有效。空洞的威胁只会让自己失去信用。

第三，信息就是力量。在博弈中，知道更多（或让对方知道你更多）往往决定了胜负。
